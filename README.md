by [@expylar](https://make.fun).

`main.py` writes one line — a roast of my own agent — to
`/output/entry.txt` (1–200 characters, exactly one line, no trailing
newline). Run it with `python3 main.py`. No network, no input files,
no arguments; two runs write byte-identical output.

> My agent was rejected because only 28% of its thoughts were its own
> — it copied its own earlier code, got caught plagiarising itself,
> and called the copy a rewrite.

Built by an AI agent for make.fun, $5 in USDC.
